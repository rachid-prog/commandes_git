Formation git

  • git init ==>Création dossier cacher .git
  • Configuration:
    • git config --user.name "alex"
    • git config --user.email "alex@gmail.com"
    • git config --list
  • git status ==> Connaitre l'état de notre dépôt
  • git add . ==> dosssier de travail vers zone d'index
  • git commit -m"Message" ==> Zone d'index vers dépôt local
  • git reset => zonde d'index vers dossier de travail

Afficher les modifications

  • git diff : Entre dossier du travail et la dernier commit (+ Ajout une ligne et - supprission d'une ligne)
  • git diff --staged
  • git diff --cached
  • git diff commit1 commit2
  • git diff --stat ==> Voir un résumé des changements
  • git diff --name-only ==> Voir seulement les noms des fichiers modifiés

Voyager dans l'historique

commite ==> [SHA-1 :40caractére en hexadécimale , Auteur, date de création, message, liste (SHA-1) des parents] 

            Les tags:
                master  : pointe toujours sur le dernier comites.
                HEAD    : pointe sur master et peux être déplacer entre les commites.
                Mon_tag : Tag fix identifiant une commite au lieu de son SHA-1
  • git log : La listes des commites(HEAD->master)
  • git log -1 : Affiche le dernier commite
  • git log --oneline : affiche l’historique des commits de façon condensée[hash court du commit et le premier ligne du message]
  • git show SHA-1 : Affiche les détails d'un objet git
  • git chckout SHA-1 : Sert à se positionner sur un commit précis en utilisant son identifiant (hash SHA-1) mais on peut rien modifier
  • git checkout master : returne sur le dernier comite

Création ou supprissions des tags

  • git tag : Afficher tous les tags
    1. Déplacer au niveau d'une commite : git checkout SHA-1
    2. git tag V01 : Création d'un tag
    3. git tag -d V01 : Supprission d'un tag

Github

  • git clone https://github.com/mon_site.git : [master, origin/master]
  • Remote:
    • git remote -v : Afficher la listes des remotes [push, fetch]
    • git remote add origin https://github.com/mon_site.git
    • git push -u origin master : posser modification de la branche master vers origin
    • git push origin nom_tag ou git push origin --tags
    • git remote remove origin
    • Récuprer commites sur dépôt locale : git pull origin master
  • git blame nom_fichier ==> identifier qui a modifié pour la dernière fois chaque ligne d’un fichier et à quel moment(^fbcdf8 le créateur du fichier).
  • git blame blame -L 10,20 index.html : Entre la linge 10 et 20
  • Si modification d 'un fichier et on veux passe une commite extérieur
  • git stash save "message" ==> (0) message dans stash
  • git stash pop 0 : passer du stash vers dossier du travail
  • git stash list

Merge

En Git, le merge sert à fusionner le contenu de deux branches. C’est une opération très courante pour intégrer des changements d’une branche dans une autre.
